# راهنمای مراحل بهبود UX — سایت مشتری

این سند مراحل پیشنهادی برای بهبود ظاهر و تجربهٔ کاربری (UX) در **customer-site** را فهرست می‌کند.

---

## ۱. Layout و ناوبری

| مرحله | توضیح | وضعیت |
|-------|--------|--------|
| منوی موبایل | منوی همبرگری با انیمیشن باز/بسته شدن | ✓ |
| Breadcrumb | مسیر ناوبری در صفحات داخلی (وبلاگ، فروشگاه، صفحه) | پیشنهاد |
| Skip link | لینک «پرش به محتوا» برای دسترسی‌پذیری | ✓ |
| فوتر | لینک‌های مهم، اطلاعات تماس، شبکه‌های اجتماعی | ✓ |

---

## ۲. صفحهٔ اصلی (Hero و محتوا)

| مرحله | توضیح | وضعیت |
|-------|--------|--------|
| Hero section | بلوک معرفی با عنوان، توضیح کوتاه و CTA | ✓ |
| کارت‌های محتوا | نمایش خلاصهٔ صفحات، مطالب وبلاگ | ✓ |
| دکمه‌های CTA | «بیشتر بدانید»، «تماس با ما» با استایل یکسان | ✓ |

| مرحله | توضیح | وضعیت |

## ۸. مراحل پیشنهادی بعدی

1. **Breadcrumb:** اضافه کردن کامپوننت breadcrumb به layout برای صفحات داخلی.
2. **صفحهٔ ۴۰۴:** طراحی صفحهٔ خطای ۴۰۴ با لینک بازگشت به خانه.
3. **Skeleton loading:** نمایش اسکلتون هنگام بارگذاری لیست‌ها (اختیاری).
4. **جستجو:** افزودن جستجو در وبلاگ و فروشگاه (در صورت نیاز).
